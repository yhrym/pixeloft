Pixeloftはアプリ本体とPostgreSQLの2つのコンテナで動きます。必要なのはComposeが使えるDockerとブラウザだけです。

## 起動する

```sh
git clone https://github.com/yhrym/pixeloft.git
cd pixeloft
docker compose up -d
```

<http://localhost:3000/setup>を開きます。既定ではポート3000で待ち受けます。変えたいときは`.env`に`PORT`を書いてください。

## 初回: /setup

ユーザーがまだいないあいだ、`/setup`では最初の管理者（ログインID・表示名・パスワード）と、最初のマップを決めます。

- **サンプルを使う**（既定）: 架空の2階建てオフィス。言語はブラウザに合わせます。
- **JSONファイルを読み込む**: [マップエディタ](../map-editor/)から書き出したマップ。
- **空で始める**: ログイン後に`/editor`で間取りを作ります。

済んだあとの`/setup`はログイン画面に飛びます。メンバーはメニューの「メンバー」で招待リンクを作って招きます。メールも外部のログインサービスも使いません。パスワードの再設定も、管理者が作る再設定リンクで行います。

## 環境変数

どれも省略できます。`docker-compose.yml`の隣の`.env`か、シェルの環境変数に書きます。

| 変数 | 既定値 | 役割 |
|---|---|---|
| `APP_URL` | 空 | `https://office.example.com`のような公開URL。招待・再設定リンクとWeb Pushの連絡先に使います。 |
| `TZ` | `Asia/Tokyo` | 最初のタイムゾーン（IANA名）。日付の切り替え・自動退出・光の色がこれに従います。 |
| `PORT` | `3000` | アプリにつなぐホスト側のポート。 |
| `TRUSTED_PROXY` | 空 | 自分で管理するリバースプロキシの後ろで動かすときに`1`にします。[運用](../operations/)を見てください。 |

それ以外は管理画面の設定（`/admin/settings`）にあります。[設定](../settings/)を見てください。

## できること

- 在室: 入室・退出・離席、15分で自動離席、日付ごとのリセット、終業後の自動退出。
- ステータス: 作業中・集中（25分）・休憩・会議中。部屋によって自動で決まるものもあります。
- 部屋ごとのチャット: 今いる部屋だけ、その日だけ、200文字まで。メンション・リアクション・60秒以内の取り消し。
- 「ちょっといい？」の声かけと手振り。Web Pushで届きます（HTTPSが必要。[通話と通知](../calls/)）。
- 時間帯で変わる光、任意の天気、季節の飾り。
- 日本語と英語。
