マップを作るだけなら、[ブラウザ版のマップエディタ](../../editor/)を登録なしで試せます。オフィスとして使うには、Pixeloftを自分のPCやサーバーで起動します。チームで使う場合は、メンバーがアクセスできる場所に置いてください。

Pixeloftはアプリ本体とPostgreSQLの2つのコンテナで動きます。用意するのはGit、Composeが使えるDocker、ブラウザです。

## 起動する

```sh
git clone https://github.com/yhrym/pixeloft.git
cd pixeloft
docker compose up -d
```

自分のPCで起動した場合は、<http://localhost:3000/setup>を開きます。サーバーで起動した場合は、そのサーバーのURLに`/setup`を付けて開いてください。待ち受けのポートは既定で3000です。変えるときは`.env`に`PORT`を書いてください。

## 初回の/setup

ユーザーが1人もいないとき、`/setup`で最初の管理者（ログインID・表示名・パスワード）と最初のマップを決めます。マップは次の3つから選びます。

- **サンプルを使う**（既定）：架空の2階建てのオフィスです。言語はブラウザの設定に合わせます。
- **JSONを読み込む**：[マップエディタ](../map-editor/)で書き出したマップを使います。
- **空のオフィスで始める**：ログイン後に`/editor`で間取りを作ります。

初期設定が終わったあとに`/setup`を開くと、ログイン画面に移ります。

## ログインして席を選ぶ

作った管理者でログインするとオフィスの画面が開きます。「入室する」を押して、空いている席を選ぶか「おまかせで座る」を押すと、キャラクターが座って同僚から見えるようになります。

「空のオフィスで始める」を選んだ場合は、ログイン後にメニューの「エディタ」を開き、部屋・入口・机を置いて「公開」を押してください。そのあと、オフィスに戻って入室します。

## メンバーを招待する

メニューの「メンバー管理」で招待リンクを作って渡します。メールも外部のログインサービスも使わないので、パスワードの再設定も、管理者が作る再設定リンクで行います。

## 必要に応じて変える設定

環境変数はどれも省略できます。`docker-compose.yml`の隣の`.env`か、シェルの環境変数に書きます。

| 変数 | 既定値 | 役割 |
|---|---|---|
| `APP_URL` | 空 | `https://office.example.com`のような公開URL。招待・再設定リンクとWeb Pushの連絡先に使います。 |
| `TZ` | `Asia/Tokyo` | 最初のタイムゾーン（IANA名）。日付の切り替え・自動退出・光の色がこれに従います。 |
| `PORT` | `3000` | アプリにつなぐホスト側のポート。 |
| `TRUSTED_PROXY` | 空 | 自分で管理するリバースプロキシの後ろで動かすときに`1`にします。詳しくは[運用](../operations/)にあります。 |

これ以外の項目は管理画面の設定（`/admin/settings`）で変えます。→[設定](../settings/)

## 主な機能

- 入室・退出・離席の状態を表示します。オフィスのタブを15分間操作しないと自動で離席になり、日付が変わるとリセットされます。設定した終業時刻を過ぎて操作がない場合は、自動で退出します。
- ステータスは作業中・集中（25分）・休憩・会議中です。部屋の種類によって自動で付くものもあります。
- チャットは部屋ごとで、今いる部屋の分がその日のあいだ表示されます。1件200文字まで送れて、メンション、リアクション、60秒以内の取り消しに対応しています。
- 「ちょっといい？」の声かけと手振りは、オフィスの画面に表示されます。「ちょっといい？」は、通知を有効にしてブラウザでも許可すると、タブを閉じていてもWeb Pushで受け取れます（HTTPSか`localhost`が必要です。[通話と通知](../calls/)）。
- 時間帯に合わせて光が変わり、天気（任意）や季節の飾りも表示できます。
- 日本語と英語を切り替えられます。
