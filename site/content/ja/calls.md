## 届くもの

- **ちょっといい？**：同僚への声かけです。相手は「行く」か「あとで」で返事をします。
- **手振り**：軽い挨拶です。受け取った側も手を振り返せます。

どちらもオフィスを開いている人の画面に表示されます。通知はオフィス画面の「呼ばれたら通知する」から有効にし、ブラウザでも許可してください。Web Pushなら、タブを閉じていても「ちょっといい？」が届きます。HTTPSか`localhost`が必要です。

## Web PushとHTTPS

Web Pushとサービスワーカーは、HTTPSか`localhost`でしか動きません。別のホストにHTTPでアクセスしていると、ブラウザは通知を出しません。アプリの前にリバースプロキシを置いてください。

### Caddyの例

Caddyなら、証明書は自動で取得されます。

```
office.example.com {
	reverse_proxy localhost:3000
}
```

先に、アプリのポートへ外部から直接アクセスできないようにしてください。`127.0.0.1`にだけ公開するか、ファイアウォールで制限します。詳しくは[運用](../operations/)を参照してください。そのうえで`.env`に次を書き、`docker compose up -d`をやり直します。

```
APP_URL=https://office.example.com
TRUSTED_PROXY=1
```

`APP_URL`は、招待・再設定リンクとWeb Pushの連絡先に使われます。`TRUSTED_PROXY`の意味は[運用](../operations/)に書いています。すべてのリクエストが確実にプロキシを通る場合にだけ設定してください。

## 通話URL

ビデオ通話や音声通話そのものは、別のサービスで行います。[設定](../settings/)で部屋ごとに通話URLを入れておくと、その部屋に通話を開くボタンが表示されます。
