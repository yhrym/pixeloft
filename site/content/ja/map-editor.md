マップエディタで間取りを作ります。真上から見た2Dのマス目で編集し、アプリと同じエンジンで描いたアイソメのプレビューで仕上がりを見ます。2か所にあります。

- **アプリの中**の`/editor`（管理者だけ）。下書きをサーバーに保存して、公開できます。
- **ブラウザだけの静的ページ**。このサイトの「ブラウザでマップを作る」ボタンから開きます。下書きはブラウザのlocalStorageに保存され、サーバーには何も送りません。ログイン・公開・版の一覧はありません。

## 置けるもの

マップは最大5階のJSONです。階ごとに次のものを置きます。

- **部屋**: 矩形（ひとつの部屋に複数の矩形も可）に名前と種類（作業・会議・休憩・フリー・共用部）を付けます。表札の位置・床の柄・屋外の指定もできます。
- **壁**と**扉**: 壁はマスの辺に沿って引き、扉は壁の上に置きます。
- **置き物**: 机・ソファ・ホワイトボード・観葉植物など、パレットから選びます。席は机や椅子などの置き物から決まります。
- **背景**: 建物の外に見える街か田舎。

1階あたり最大64×64マス。マップ名などの文字は40文字まで、JSONは2MBまでです。

## 画面の構成

いちばん左が道具の列（選択・部屋・壁・扉・置き物）で、その隣に検索とカテゴリ付きの置き物パレットがあります。真ん中が2Dの図面で、上に階のタブ、隅にズームがあります。右のパネルには、アイソメのプレビュー（「拡大」で大きくなります）、選んだものの「プロパティ」、「チェック」が並びます。右上の「…」メニューに、JSON書き出し・JSON読み込み・サンプルを開く・ショートカットの一覧があります。

## 道具

| 道具 | できること |
|---|---|
| 選択 | クリックで選びます。置き物はドラッグで動かせて、部屋は角をドラッグすると広げられます。 |
| 部屋 | ドラッグで部屋を作ります。描いた直後に「部屋の設定」の小さなポップオーバーが出て、名前と種類を決められます。<kbd>Shift</kbd>を押しながらドラッグすると、新しい部屋を作らず、選んだ部屋に矩形を足せます。 |
| 壁 | マスの辺に沿ってドラッグして壁を引きます。図面の上のボタンでまとめても引けます。「外壁を自動で引く」と「部屋の境目に壁を引く」で、それぞれ壁の種類を選べます。 |
| 扉 | 壁にカーソルを置いてクリックすると扉を置けます。 |
| 置き物 | パレットから選んで、図面をクリックして置きます。パレットから図面へのドラッグ&ドロップでも置けます。 |

## ショートカット

エディタで<kbd>?</kbd>を押すと同じ一覧が出ます。

| 操作 | キー |
|---|---|
| 選択 | <kbd>V</kbd>または<kbd>1</kbd> |
| 部屋・壁・扉・置き物 | <kbd>2</kbd>、<kbd>3</kbd>、<kbd>4</kbd>、<kbd>5</kbd> |
| 選んだ置き物を回す | <kbd>R</kbd>。<kbd>Shift</kbd>+<kbd>R</kbd>で逆向き |
| 選んだものを消す | <kbd>Delete</kbd>または<kbd>Backspace</kbd> |
| 動かす | 矢印キー。置き物を選んでいれば1ステップ（8）ずつ、何も選んでいなければ画面を動かします |
| 元に戻す・やり直す | <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Z</kbd>、<kbd>Shift</kbd>+<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Z</kbd>（<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Y</kbd>でも可） |
| 保存 | <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>S</kbd> |
| 複製 | <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>D</kbd> |
| 拡大・縮小 | マウスホイール、<kbd>+</kbd> / <kbd>-</kbd> |
| 画面の移動 | <kbd>Space</kbd>を押しながらドラッグ、または右ボタン・中ボタンのドラッグ |
| 選んだ部屋に矩形を足す | 部屋の道具で<kbd>Shift</kbd>を押しながらドラッグ |
| 選択を外す・ポップオーバーやダイアログを閉じる | <kbd>Esc</kbd> |

編集は、手を止めて少しするとひとりでに保存されます（上のバッジが「保存済み」「未保存」「保存中」と変わります）。

## はじめてのマップのチェックリストとチェック

空のマップには、「はじめてのマップ」という小さなチェックリストが出ます。部屋を作る、入口を置く、机を置く、書き出す（アプリ版では公開する）の順です。閉じることもできます。

右パネルの「チェック」には、編集中に見つかった問題が並びます。直し方のボタンが付くものがあります。階に入口がないときの「入口を探す」はエレベーター・階段・入口の扉を光らせ、「扉を置く」は部屋を選んだまま扉の道具に切り替え、「相手を選ぶ」は重なっている相手のほうを選びます。

## ブラウザ版とインスタンスの間でJSONを渡す

どちらも同じ形式のJSONで、`version`の欄があります。

**ブラウザからインスタンスへ**

1. ブラウザ版で「JSONを書き出す」を押します。
2. 自分のインスタンスの`/editor`で「JSONを読み込む」を押し、一覧に出たエラーを直します。
3. 「公開」を押します。

最初の`/setup`でファイルを選ぶこともできます。

**インスタンスからブラウザへ**

1. `/editor`で「JSONを書き出す」を押します。
2. ブラウザ版で「JSONを読み込む」を押します。

「サンプルを開く」は、同梱の架空のオフィスを下書きにします。下書きが空でないときは先に確認が出ます。元に戻すで前の下書きに戻れますが、先に書き出しておくほうが安全です。

## 公開

アプリ版では「下書きを保存」で作業中の内容を残し、「公開」で本番のマップにします。

公開の前にサーバーがマップを検証し、直すところを一覧で出します。部屋の外にある席、重なり、上限超え、入口がない、などです。エラーがあると公開できず、警告は公開を止めません。同じ検査は編集中のエディタにも出ます。

公開するたびに新しい版が増えます。「版」の一覧から古い版を選んで「この版を公開」すると、新しい版として公開し直せます。カタログの置き物のidは消さないので、古いマップもそのまま動きます。

### 座っている人はどうなるか

公開したとき、席や部屋がなくなった人は、**席なし**で共有のスペースに移され、本人には「席がなくなりました」と出ます。そのあと自分で新しい席を選べます。ほかの人はそのままです。人がいる時間に公開するときは、先にプレビューと検証の一覧を確認してください。
