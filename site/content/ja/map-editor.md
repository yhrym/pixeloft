マップエディタでは真上から見た2Dのマス目で間取りを編集し、アプリと同じエンジンで描いた斜め見下ろし（アイソメ）のプレビューで仕上がりを確認します。エディタは次の2か所で使えます。

- **アプリの中の`/editor`**（管理者のみ）：下書きをサーバーに保存して公開できます。
- **ブラウザだけで動く静的ページ**：[ブラウザ版のマップエディタ](../../editor/)を登録なしで開けます。はじめて開いたときはサンプルのオフィスが表示されるので、机をドラッグして動かしてみてください。下書きはブラウザのlocalStorageに保存され、サーバーには何も送りません。ログイン、公開、版の一覧はありません。

## 置けるもの

1つのマップには最大5階まで作れます。マップはJSON形式で保存され、各階には次のものを置けます。

- **部屋**：矩形に名前と種類（作業・会議・休憩・フリー・共用部）を付けます。ひとつの部屋に複数の矩形を使えます。表札の位置、床の柄、屋外かどうかも指定できます。
- **壁**と**扉**：壁はマスの辺に沿って引き、扉は壁の上に置きます。
- **置き物**：机、ソファ、ホワイトボード、観葉植物などをパレットから選んで置きます。席になるのは、机や椅子などの置き物です。
- **背景**：建物の外に見える街か田舎。

上限は、1階あたり64×64マス、マップ名などの文字が40文字、JSONが2MBです。

## 画面の構成

いちばん左に道具の列（選択・部屋・壁・扉・置き物）があり、その隣に検索とカテゴリ付きの置き物パレットがあります。真ん中が2Dの図面で、上に階のタブ、隅にズームがあります。右のパネルにはアイソメのプレビュー（「拡大」で大きくなります）、選んだものの「プロパティ」、「チェック」が並びます。右のパネルは左の境目を、プレビューは下の境目をドラッグすると広げられます（ダブルクリックで元の大きさに戻ります）。右上の「…」メニューからは「JSON書き出し」「JSON読み込み」「サンプルを開く」とショートカットの一覧（ブラウザ版では「使い方（ドキュメント）」も）を使えます。

## 道具

| 道具 | できること |
|---|---|
| 選択 | クリックで選びます。置き物は乗っているマスのどこをクリックしても選べて、そのままドラッグで動かせます。部屋は角をドラッグして広げます。 |
| 部屋 | ドラッグで部屋を作ります。描き終えると「部屋の設定」の小さな吹き出しが出るので、そこで名前と種類を決めます。<kbd>Shift</kbd>を押しながらドラッグすると、新しい部屋は作らず、選んでいる部屋に矩形を足します。 |
| 壁 | マスの辺に沿ってドラッグして引きます。図面の上のボタンでまとめて引くこともできます。「外壁を自動で引く」と「部屋の境目に壁を引く」では、それぞれ壁の種類を選べます。 |
| 扉 | 壁にカーソルを合わせてクリックすると置けます。 |
| 置き物 | パレットから選んで、図面をクリックして置きます。パレットから図面へドラッグ&ドロップしても置けます。 |

## ショートカット

エディタで<kbd>?</kbd>を押すと、同じ一覧が表示されます。

| 操作 | キー |
|---|---|
| 選択 | <kbd>V</kbd>または<kbd>1</kbd> |
| 部屋・壁・扉・置き物 | <kbd>2</kbd>、<kbd>3</kbd>、<kbd>4</kbd>、<kbd>5</kbd> |
| 選んだ置き物を回す | <kbd>R</kbd>（<kbd>Shift</kbd>+<kbd>R</kbd>で逆向き） |
| 選んだものを消す | <kbd>Delete</kbd>または<kbd>Backspace</kbd> |
| 動かす | 矢印キー。置き物を選んでいれば半マスずつ動かし、何も選んでいなければ画面を動かします |
| 元に戻す・やり直す | <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Z</kbd>、<kbd>Shift</kbd>+<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Z</kbd>（<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>Y</kbd>でも可） |
| 保存 | <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>S</kbd> |
| 複製 | <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>D</kbd> |
| 拡大・縮小 | マウスホイール、<kbd>+</kbd> / <kbd>-</kbd> |
| 画面の移動 | <kbd>Space</kbd>を押しながらドラッグ、または右ボタン・中ボタンのドラッグ |
| 選んだ部屋に矩形を足す | 部屋の道具で<kbd>Shift</kbd>を押しながらドラッグ |
| 選択を外す・吹き出しやダイアログを閉じる | <kbd>Esc</kbd> |

編集内容は、操作が止まってしばらくすると自動で保存されます。上のバッジの表示は「保存済み」「保存していません」「保存中…」と切り替わります（ブラウザ版では「このブラウザに保存済み」）。ブラウザ版は公開ボタンの代わりに、上のバーに「JSON書き出し」ボタンがあります。

## マップ作成の案内と問題の確認

空のマップには「はじめてのマップ」という小さなチェックリストが出ます。項目は、部屋を作る、入口を置く、机を置く、書き出す（アプリ版では公開する）の順で、閉じることもできます。

右パネルの「チェック」には、編集中に見つかった問題が並びます。直し方のボタンが付いているものもあります。階に入口がないときの「入口を探す」は、エレベーター・階段・入口の扉を光らせます。「扉を置く」は部屋を選んだまま扉の道具に切り替えます。「相手を選ぶ」は重なっている相手のほうを選択します。

## ブラウザ版とインスタンスの間でJSONを渡す

ブラウザ版とインスタンスは同じ形式のJSONを読み書きします。JSONには形式の版を表す`version`が入っています。

**ブラウザからインスタンスへ**

1. ブラウザ版で「JSON書き出し」を押します。
2. 自分のインスタンスの`/editor`で「JSON読み込み」を押し、一覧に出たエラーを直します。
3. 「公開」を押します。

初回の`/setup`でファイルを選んで読み込むこともできます。

**インスタンスからブラウザへ**

1. `/editor`で「JSON書き出し」を押します。
2. ブラウザ版で「JSON読み込み」を押します。

「サンプルを開く」を押すと、同梱の架空のオフィスが下書きになります。今の下書きが空でなければ、先に確認が出ます。元に戻す操作で前の下書きに戻れますが、事前にJSONを書き出しておくほうが安全です。

## 公開

アプリ版でも、編集内容は下書きとしてサーバーに自動で保存されます（<kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+<kbd>S</kbd>ですぐに保存することもできます）。下書きはオフィスには出ません。「公開」を押すと本番のマップになります。

公開する前にサーバーがマップを検証し、直す箇所を一覧にして返します。たとえば、部屋の外にある席、置き物の重なり、上限の超過、入口がないといったものです。エラーが残っていると公開できません。警告は公開を止めません。同じ検査の結果は編集中のエディタにも表示されます。

公開するたびに新しい版が追加されます。「版の一覧」から古い版を選んで「この版を公開」を押すと、新しい版として公開し直せます。カタログの置き物のidは削除しないので、古いマップもそのまま動きます。

### 座っている人の扱い

公開によって席や部屋がなくなった人は、**席なし**の状態で共用部に移され、本人の画面に「席がなくなりました」と表示されます。あとで自分で新しい席を選べます。ほかの人には影響しません。人がいる時間帯に公開するときは、先にプレビューと検証の一覧を確認してください。
